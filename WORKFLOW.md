# AI-Assisted Workflow Drill - Todo List App

## Round 1 (Vague Prompt)
**Prompt:** "Create a todo list app."

**Result:** Basic functional todo list with add/delete and localStorage.
- Simple UI
- Works but basic styling
- No completed count, no nice UX

## Round 2 (Precise Prompt)
**Prompt:** Detailed requirements with modern UI, stats, accessibility, etc.

**Result:** Much better version with:
- Modern clean design
- Task completion count
- Better UX and responsiveness
- Improved code structure

## Comparison
- **Time:** Round 1 was faster but low quality. Round 2 took more time but produced production-ready output.
- **Quality:** Round 2 is significantly better in design, UX, and code organization.
- **AI Mistake Caught:** Vague prompt gave very basic result. Precise prompt forced better structure and features.

## Lessons Learned
1. Vague prompts give generic results.
2. Precise prompts with clear requirements and tech stack produce much better output.
3. Always specify UI, functionality, and constraints.

## Rules for CLAUDE.md
1. Always ask for tech stack (HTML/CSS/JS or React) before starting.
2. Require modern UI, accessibility, and responsiveness in every UI task.
3. For forms, always include validation, localStorage, and stats.
